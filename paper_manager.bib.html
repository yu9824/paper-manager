paper_manager.bib package#

BibTeXファイルの読み込み機能を提供するモジュール。

このモジュールは、BibTeX形式のファイルから論文情報を読み込む 機能を提供します。

主な関数:

load_bib: BibTeXファイルまたは文字列から論文エントリを読み込む format_person: BibTeXの人名を <名> <姓> の形に整形する

例:
>>> from paper_manager.bib import load_bib
>>> from io import StringIO
>>> bib_text = '''
... @article{example,
...   title={Example Paper},
...   author={John Doe},
...   year={2024}
... }
... '''
>>> entries = load_bib(StringIO(bib_text))
>>> len(entries)
1
paper_manager.bib.format_person(person: Person) → str#

BibTeX の人名を <名> <姓> の形の文字列に整形する。

名は first_names と middle_names、姓は prelast_names （van der などの前置詞）と last_names を空白でつなぎ、空でない 部分を <名> <姓> の順に並べます。単純な First Last と Last, First の名前は "First Last" になります。

接尾辞（lineage_names。Jr. など）があるときは、BibTeX の正規形 von Last, Jr, First にします。<名> <姓> の形ではエクスポート時の 再解析で接尾辞が姓として読まれ、姓と名が入れ替わるためです。名か姓が 空でも区切りの , は残します（接尾辞が名や姓として読まれないように するため）。

Parameters:

person (pybtex.database.Person) – 整形する人名

Returns:

整形した人名。名・姓・接尾辞のすべてが空なら空文字列

Return type:

str

Examples

>>> from pybtex.database import Person
>>> format_person(Person("Smith, John"))
'John Smith'
>>> format_person(Person("van der Waals, Johannes Diderik"))
'Johannes Diderik van der Waals'
>>> format_person(Person("King, Jr., Martin Luther"))
'King, Jr., Martin Luther'
paper_manager.bib.load_bib(bibtexfile_or_buffer: PathLike | str | BytesIO | StringIO) → MappingProxyType#

BibTeXファイルまたは文字列から論文エントリを読み込む。

BibTeX形式のファイル、文字列、またはファイルオブジェクトから 論文エントリを読み込み、辞書形式で返します。

Parameters:

bibtexfile_or_buffer (Union[os.PathLike, str, io.BytesIO, io.StringIO]) – BibTeXファイルのパス、文字列、またはファイルオブジェクト

Returns:

エントリの辞書（``{cite_key: entry}``の形式） 各エントリは、フィールド名をキーとする辞書です。

Return type:

MappingProxyType[str, MappingProxyType[str, str]]

Examples

>>> from paper_manager.bib import load_bib
>>> from pathlib import Path
>>> entries = load_bib(Path("./sample.bib"))
>>> len(entries)
1

文字列から読み込む場合:

>>> from io import StringIO
>>> bib_text = '@article{example, title={Example}, author={John Doe}}'
>>> entries = load_bib(StringIO(bib_text))
>>> entries['example']['title']
'Example'

Notes

  • 著者名は format_person() で整形され、” and “ で結合されます。 整形した結果が空の人名は捨てます

  • 著者が 1 人もいないエントリ（著者のない BibTeX など）には author の項目を作りません（空文字列の著者は必須項目の判定を通ってしまうため）

  • エントリタイプは ENTRYTYPE フィールドに追加されます
