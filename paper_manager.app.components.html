paper_manager.app.components.custom_entry(entry: Entry) → Entry#

エントリタイプに基づいて入力フィールドを動的に生成し、 ユーザーが入力した値でEntryオブジェクトを更新する。

  • 著者は AUTHOR_SEPARATOR (`` and ) で、タグは ``TAG_SEPARATOR (, ``) で、既定値を選択肢に分け、保存時に連結 する。変更しなければ表記は変わらない。, `` 区切りで保存済みの著者は 1 つの選択肢として、そのまま保存される。

  • 年は、保存されている値が空か有効なら数値入力で入力する。無効 (整数 として往復しない、または入力できる範囲の外) なら、警告を出して文字の 入力欄に切り替える。触らなければ元の値を保ち、入力し直せばその値で 保存する。

paper_manager.app.components.delete_pdfs(entry: Entry, base_dir: Path | None = None, specific_files: list[Path] | None = None) → int#

PDFファイルを削除する。

削除は、ファイル操作用に変換したパス (to_fs_path。Windows では 拡張長のパス) で行う。specific_files は変換前のパスでも変換後の パスでもよい。PDFフォルダが空かどうかの判定やPDFルートとの比較は、 変換後のパスどうしで行う。

エントリのPDFフォルダがPDFルートの直下の名前でないとき (フォルダ名の 計算結果が空や .. などで、PDFルートそのもの、またはその外を指す とき) は、フォルダを削除しない。

ファイルやフォルダの削除に失敗したら、そのパス (表示用のパス) と理由 をログと画面に出し、残りの削除を続ける。

Parameters:

  • entry (Entry) – 対象の論文エントリ

  • base_dir (Union[Path, None], optional) – PDFの基本ディレクトリ。Noneの場合はDIRPATH_PDFを使用。

  • specific_files (Optional[list[Path]], optional) – 削除する特定のファイル。Noneの場合は全PDFを削除（PDFフォルダごと、 および移せなかった旧形式の単一PDFを削除）。

Returns:

削除したファイル数。削除に失敗したものは数えない。

Return type:

int

paper_manager.app.components.register_entry_to_list(paper_list: PaperList, entry: Entry, uploaded_files: list[UploadedFile] | None = None) → bool#

論文エントリをリストに登録する。

重複チェックを行い、PDFファイルがあれば保存する。重複は、既存の全論文と PDFフォルダ名の比較キー (folder_name_key) が一致するかで判定する (大文字小文字やUnicode正規化だけが違う名前も重複。ファイルシステムが 大文字小文字を区別するかにかかわらず、すべてのOSで同じ)。重複なら エラーを出し、論文リストもPDFも変えない。

Parameters:

  • paper_list (PaperList) – 論文リスト

  • entry (Entry) – 登録する論文エントリ

  • uploaded_files (Optional[list[UploadedFile]]) – アップロードされたPDFファイルのリスト

Returns:

登録成功した場合True。重複、または壊れた論文リストのファイルを退避 できずに保存しなかった場合は、論文リストを変えずにFalse

Return type:

bool

paper_manager.app.components.save_paper_list(paper_list: PaperList) → bool#

PaperListをセッションステートとファイルに保存する。

書き込みの前に、論文リストのファイルの状態を確かめる (保存の直前に 実ファイルを判定するので、画面を開いた後にファイルが壊れた場合も 見逃さない)。壊れていれば、別名のファイル (list.json.broken-<日時>) へ退避してから書く。退避先 (表示用のパス) は、ログと画面 (st.warning) に出す。画面の再描画で消えないよう、同じ文言を session state の通知 (KEY_NOTICES) にも残す。通知は、次の描画で config_page が 表示してから消す。ファイルがない、または壊れていなければ、退避せずに 書く。

壊れたファイルを退避できなかった (またはファイルを読めず、状態を確かめ られなかった) ときは、壊れたファイルの内容を失わないよう、何も書かずに エラーをログと画面に出して False を返す。session state も変えない。

Parameters:

paper_list (PaperList) – 保存する論文リスト

Returns:

保存した場合True。退避できずに保存しなかった場合False。

Return type:

bool

paper_manager.app.components.save_pdfs(uploaded_files: list[UploadedFile], entry: Entry, base_dir: Path | None = None, failures: list[str] | None = None) → int#

複数のPDFファイルを保存する。

保存先は、ファイル操作用に変換したパス (Entry.get_pdf_dir。 Windows では拡張長のパス) なので、パス全体の長さにかかわらず保存する。 フォルダの作成やファイルの書き込みに失敗したら、そのパス (表示用の パス) と理由をログと画面に出し、残りのファイルの処理を続ける。

画面のエラーは、画面が再描画されると消える。呼び出し元がその後も失敗を 伝えられるよう、failures を渡すと、画面 (st.error) に出したものと 同じ文 (表示用のパスと理由。変換後の prefix は含まない) を、失敗ごとに 1 文ずつ追加する。成功したファイルの分は何も追加しない。省略すると、 これまでと同じ振る舞いになる。

Parameters:

  • uploaded_files (list[UploadedFile]) – アップロードされたPDFファイルのリスト

  • entry (Entry) – 対象の論文エントリ

  • base_dir (Union[Path, None], optional) – PDFの基本ディレクトリ。Noneの場合はDIRPATH_PDFを使用。

  • failures (Optional[list[str]], optional) – 失敗の文を追加する一覧。渡された一覧の既存の中身は残し、後ろに 追加する。

Returns:

保存したファイル数

Return type:

int

paper_manager.app.components.update_entry_in_list(paper_list: PaperList, key_original: str, entry_updated: Entry, uploaded_files: list[UploadedFile] | None = None, failures: list[str] | None = None) → bool#

論文エントリを更新する。

PDFフォルダ名が変わらない更新は、そのまま更新する。変わる更新は、自分 以外の論文とPDFフォルダ名の比較キー (folder_name_key) が一致する なら重複として拒否する (大文字小文字やUnicode正規化だけが違う名前も重複。 ファイルシステムが大文字小文字を区別するかにかかわらず、すべてのOSで 同じ)。重複でなければ、PDFフォルダを新しい名前へ改名してから更新する。

改名の前に、元の論文の旧形式の単一PDFと修正前の名前のフォルダの移行 (Entry.get_pdf_files) を済ませるので、改名後も新しい名前のフォルダの PDFとして見える。移行は既存のPDFを上書きせず、一覧の表示でも起きる。

大文字小文字 (またはUnicode正規化) だけが変わる改名は、一時名を経由して 行う。改名先が元のフォルダ自身でない既存のフォルダなら、上書き・統合せず に拒否する。拒否・失敗したとき (False) は、論文リストを変えず、PDF フォルダは元の名前に保つ (一時名からも戻せなかったときだけ、一時名の場所を エラーに含める)。

追加したPDFの一部を保存できなくても、論文を保存できれば True を返す (保存の失敗は save_pdfs が画面に出す)。呼び出し元が更新の後に再描画 すると画面のエラーは消えるので、failures を渡すと、更新に成功した ときだけ、保存に失敗したPDFの文 (save_pdfs が画面に出したものと同じ 文) を追加する。更新を拒否・中止して False を返すときは、 failures を変えない (再描画しなければ、画面のエラーが残る)。

Parameters:

  • paper_list (PaperList) – 論文リスト

  • key_original (str) – 更新する論文の元のキー

  • entry_updated (Entry) – 更新後の論文エントリ

  • uploaded_files (Optional[list[UploadedFile]]) – アップロードされたPDFファイルのリスト

  • failures (Optional[list[str]], optional) – 追加したPDFの保存の失敗の文を追加する一覧。渡された一覧の既存の 中身は残し、後ろに追加する。省略すると、これまでと同じ振る舞いに なる。

Returns:

更新成功した場合True。重複、改名の失敗、または壊れた論文リストの ファイルを退避できずに保存しなかった場合は、論文リストを変えずに False

Return type:

bool
