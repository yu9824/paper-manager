バックアップ・復元ガイド#

paper-managerには、データをバックアップ・復元する機能が用意されています。このガイドでは、バックアップと復元の方法について説明します。

バックアップ機能#

バックアップ機能を使用すると、以下のデータをzipファイルにまとめて保存できます：

  • paper-managerのバージョン情報

  • 論文リスト（list.json）

  • 設定ファイル（config.json、プロキシ設定など）

  • すべてのPDFファイル

Webアプリケーションからバックアップを作成#

  1. アプリケーションの「バックアップ」ページに移動

  2. 「バックアップを作成」ボタンをクリック

  3. ダウンロードボタンからzipファイルをダウンロード

バックアップファイル名は paper-manager-backup_YYYYMMDD_HHMMSS.zip の形式になります。

コマンドラインからバックアップを作成#

# デフォルトのファイル名でバックアップを作成
paper-manager backup

# カスタムファイル名を指定
paper-manager backup -o my-backup.zip

復元機能#

バックアップファイルからデータを復元できます。復元を実行すると、現在のデータが上書きされます。

Webアプリケーションから復元#

  1. アプリケーションの「復元」ページに移動

  2. バックアップzipファイルをアップロード

  3. バックアップファイルの内容を確認

  4. 「復元を実行」ボタンをクリック

注意事項:

  • 復元を実行すると、現在のデータが上書きされます

  • 既存のlist.jsonは自動的に.json.backupとしてバックアップされます

  • 既存のconfig.jsonも自動的に.json.backupとしてバックアップされます

  • 復元後はページを再読み込みしてください

コマンドラインから復元#

# 確認を求めて復元
paper-manager restore backup.zip

# 確認なしで復元（--forceオプション）
paper-manager restore backup.zip --force

復元時に確認が求められます。続行する場合は yes または y を入力してください。

バックアップファイルの構造#

バックアップzipファイルには以下のファイルが含まれます：

paper-manager-backup_YYYYMMDD_HHMMSS.zip
├── version.json          # バージョン情報とバックアップ日時
├── list.json             # 論文リスト
├── config.json           # 設定ファイル（存在する場合）
└── pdf/                  # PDFファイルディレクトリ
    ├── 2024 - Author - Title/
    │   ├── 00.pdf        # 最初のPDFファイル
    │   ├── 01.pdf        # 2番目のPDFファイル（存在する場合）
    │   └── 02.pdf        # 3番目のPDFファイル（存在する場合）
    └── ...

注意: バージョン2.0.0以降では、各エントリごとに専用のディレクトリが作成され、 その中に00.pdf, 01.pdfのように連番で命名されたPDFファイルが保存されます。 旧バージョン（1.x系）のバックアップファイルも復元可能で、自動的に新しい形式に移行されます。

バージョン互換性#

  • 古いバージョンのバックアップファイルも復元可能です

  • config.jsonが含まれていない古いバックアップファイルでもエラーになりません

  • バックアップ時のバージョン情報は復元時に表示されます

トラブルシューティング#

復元が失敗する場合#

  • zipファイルが破損していないか確認してください

  • バックアップファイルがpaper-managerの形式であることを確認してください

  • エラーメッセージを確認し、必要な権限があることを確認してください

データが上書きされた場合#

復元前に既存のファイルは自動的にバックアップされます：

  • list.json → list.json.backup

  • config.json → config.json.backup

これらのバックアップファイルから手動で復元できます。
