# 使用方法ガイド

このガイドでは、paper-managerの基本的な使用方法について説明します。

## アプリケーションの起動

### 基本的な起動方法

```bash
paper-manager run
```

これにより、Streamlitサーバーが起動し、デフォルトのブラウザでアプリケーションが開きます。

### 開発モードでの起動

```bash
paper-manager run --debug --server.address localhost
```

開発モードでは、より詳細なログが表示されます。

## ページ構成

paper-managerのアプリケーションは以下のページで構成されています：

### リスト・編集ページ

論文一覧を表示し、選択した論文の詳細を表示・編集・削除できます。

**主な機能:**
- 論文一覧の表示（テーブル形式）
- 論文の選択（単一または複数）
- 論文詳細の表示
- 論文の編集
- 論文の削除
- PDFファイルの表示・ダウンロード
- BibTeX/XML形式でのエクスポート
- 孤立PDFファイルの検出・削除

**統計情報:**
- 総論文数
- PDFファイル数
- PDFあり/なしの論文数
- 孤立PDFファイル数

### 登録ページ

新しい論文を登録できます。以下の3つの方法があります：

#### 1. BIB形式から登録

BibTeX形式のテキストまたはファイルから論文を登録します。

**手順:**
1. 「📄 BIB」タブを選択
2. BibTeX形式のテキストを入力するか、`.bib`ファイルをアップロード
3. PDFファイルをアップロード（オプション）
4. 「📤 登録」ボタンをクリック

#### 2. DOIから自動取得

DOIを入力すると、自動的にメタデータを取得して登録します。

**手順:**
1. 「🔗 DOI」タブを選択
2. DOIを入力（例: `10.1107/S0567739476001551`）
3. PDFファイルをアップロード（オプション）
4. 「📤 登録」ボタンをクリック

**注意:** プロキシ環境の場合は、事前にプロキシ設定を行ってください。

#### 3. カスタム入力

手動で論文情報を入力して登録します。

**手順:**
1. 「✏️ CUSTOM」タブを選択
2. エントリタイプを選択（article, book, inproceedingsなど）
3. 必須フィールドを入力
4. PDFファイルをアップロード（オプション）
5. 「📤 登録」ボタンをクリック

### バックアップページ

データのバックアップを作成できます。詳細は[バックアップ・復元ガイド](backup_restore.md)を参照してください。

### 復元ページ

バックアップファイルからデータを復元できます。詳細は[バックアップ・復元ガイド](backup_restore.md)を参照してください。

### 設定ページ

アプリケーションの設定を管理できます。現在はプロキシ設定が利用可能です。詳細は[プロキシ設定ガイド](proxy_settings.md)を参照してください。

## 論文の管理

### 論文の編集

1. リストページで論文を選択
2. 「✏️ 編集」ボタンをクリック
3. 情報を編集
4. PDFファイルを追加（オプション）
5. 「✓ Done」ボタンをクリック

### 論文の削除

1. リストページで論文を選択
2. PDFファイルも削除する場合はチェックボックスを選択
3. 「🗑️ 削除」ボタンをクリック

### 複数論文の一括操作

1. リストページで複数の論文を選択
2. 以下の操作が可能：
   - 一括削除
   - BibTeX/XML形式でのエクスポート
   - PDFファイルのzipダウンロード

## PDFファイルの管理

### PDFファイルの追加

論文登録時または編集時にPDFファイルをアップロードできます。複数のPDFファイルを追加することも可能です。

### PDFファイルの表示

1. リストページで論文を選択
2. PDFファイルが自動的に表示されます
3. 複数のPDFがある場合は、ドロップダウンから選択

### PDFファイルのダウンロード

PDFビューアの横にあるダウンロードボタンから、個別のPDFファイルをダウンロードできます。

## エクスポート機能

### BibTeX形式でのエクスポート

1. リストページで論文を選択（単一または複数）
2. 「💾 エクスポート」セクションで「bib」を選択
3. 「📄 BibTeXファイルをダウンロード」ボタンをクリック

### XML形式でのエクスポート

1. リストページで論文を選択（単一または複数）
2. 「💾 エクスポート」セクションで「xml」を選択
3. 「📄 XMLファイルをダウンロード」ボタンをクリック

### PDFファイルのzipダウンロード

複数の論文を選択した場合、PDFファイルをzip形式でダウンロードできます。

## 孤立PDFファイルの管理

論文リストに紐づいていないPDFファイル（孤立PDF）を検出・削除できます。

1. リストページの統計情報で「⚠️ 孤立PDF」の数を確認
2. 孤立PDFがある場合、警告が表示されます
3. 「🔍 孤立したPDFファイルの詳細」を展開して確認
4. 「🗑️ すべての孤立PDFを削除」ボタンで削除

## データの保存場所

デフォルトでは、以下の場所にデータが保存されます：

- **データディレクトリ**: `~/.paper-manager/`
- **論文リスト**: `~/.paper-manager/list.json`
- **設定ファイル**: `~/.paper-manager/config.json`
- **PDFファイル**: `~/.paper-manager/pdf/`

環境変数 `PAPER_MANAGER_DATA_DIR` を設定することで、データディレクトリを変更できます。

## トラブルシューティング

### アプリケーションが起動しない場合

- Pythonのバージョンが3.9以上であることを確認してください
- 必要なパッケージがインストールされているか確認してください
- エラーメッセージを確認してください

### DOI取得が失敗する場合

- DOIが正しいか確認してください
- インターネット接続を確認してください
- プロキシ環境の場合は、プロキシ設定を確認してください

### PDFファイルが表示されない場合

- PDFファイルが正しくアップロードされているか確認してください
- ファイルパスに問題がないか確認してください
- ブラウザのコンソールでエラーを確認してください
